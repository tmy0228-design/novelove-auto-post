# 通常記事サンプル画像（1枚・任意表示）— 設計メモ

ステータス: **合意済み・未実装**（2026-08-07）  
目的: 別環境／別セッションでも同じ方針で実装できるように固定する。

---

## 1. プロダクト方針

- 記事冒頭は現状維持（アイキャッチ → スペック → 担当者一言 → 最初の説明）。
- サンプルは **最初の簡単な説明（最初の h2 配下の本文）の直後** に置く。
- **あれば 1 枚だけ表示。無ければセクション自体を出さない。**
- 完全たたみより「1枚見せる」で気づきを担保。追加の横並び2枚・大量ギャラリーはしない（ごちゃつき回避）。
- **公式サンプル／立ち読み専用ボタンは作らない**（既存アフィ CTA で足りる）。
- 値段は載せない方針は維持（ストア誘導）。

対象は **通常記事のみ**:

```sql
WHERE post_type = 'regular'
```

まとめ・ランキング等は対象外。

---

## 2. ストア別：取れるもの／取れないもの

実測（本番サーバー経由, 2026-08-07）。

| ストア | 静的サンプル画像 | 取得方法 | 備考 |
|--------|------------------|----------|------|
| **DLsite RJ（同人）** | 高い確率で可 | 詳細HTMLの `img.dlsite.jp/.../modpub/..._img_smpN.jpg` | `resize/...100x100` は使わない |
| **DLsite BJ（商業）** | ほぼ不可 | 同上を試して空ならスキップ | BJ ≒ 商業電子書籍。サンプル欄が薄い |
| **らぶカル** | 高い確率で可 | **DMM API** `sampleImageURL.sample_l.image[]` の `...jp-00N.jpg` | `js-00N` は120pxサムネなので使わない |
| **DMM商業 ebook** | 画像URLなし | API `tachiyomi.URL` / `affiliateURL` は**ビューアリンクのみ** | 埋め込み向きでない。専用ボタンも作らない |

公開通常記事の母数イメージ（当時）:

- `post_type=regular AND status=published` ≈ **4093**
- DLsite 2631（RJ≈1718 / BJ≈913） / らぶカル≈634 / DMM≈828
- 静的サンプル付きにできるのはざっくり半分前後。残りはセクションなしでよい。

向きの目安（表示ルールは「常に1枚」で単純化で合意）:

- 横長・縦長とも **表示は1枚**
- らぶカル `jp-*` は原寸が大きい（例: 約2000px）→ CSS `max-width: 640〜720px; height: auto;`

1枚目の中身は作品によってバラつく（煽りコラージュ／本文ページ等）。題名・目次だけの可能性はあるが、常にそうではない。選別ロジックは初期は不要（取れれば1枚目）。

---

## 3. ロールアウト

件数が多いので一括は重い。

1. **新規投稿から適用**（本命）
2. **既存は後回し**  
   - 放置でも可  
   - やるなら裏バッチで細切れ（例: 1日数十〜百件、`post_type=regular` かつ未処理のみ）  
   - 優先するなら DLsite RJ＋らぶカル

## 4. 実装スケッチ（未着手）

### データ

- 現状 DB は `image_url`（表紙）のみ。サンプル配列は未保存。
- 追加案（どれか）:
  - `sample_image_url TEXT`（採用1枚だけ）
  - または `sample_image_urls TEXT`（JSON配列。表示は先頭1枚）
- 未取得／無しは空。空なら HTML にセクションを出さない。

### 取得

- **らぶカル**: fetcher の ItemList 応答から `sampleImageURL.sample_l.image[0]` を保存（スクレイプ不要）。
- **DLsite**: 詳細ページから `_img_smp1.jpg`（あれば）を保存。BJ で空なら空のまま。
- **DMM商業**: サンプル画像フィールドは触らない（tachiyomi もボタン化しない）。

### 表示

- 投稿／リライト時、本文の「最初の説明ブロックの直後」にマーカー付きブロックを挿入。例:

```html
<!-- NOVELOVE_SAMPLE_START -->
<figure class="novelove-sample">
  <img src="..." alt="サンプル" loading="lazy" decoding="async" width="..." height="...">
</figure>
<!-- NOVELOVE_SAMPLE_END -->
```

- URL が空ならマーカーごと挿入しない。
- 再投稿・リライト時は既存マーカーを消してから差し替え（スペック表と同じガード）。

### 挿入位置（現行構成）

実記事の entry-content 冒頭は概ね:

1. スペック（`novelove-specs`）
2. 担当者の最初の吹き出し
3. 最初の `h2` ＋説明 `<p>`…
4. ← **ここにサンプル（任意）**
5. 次の吹き出し／以降セクション

「一言の直後」ではなく「最初の説明の後」。

## 5. やらないこと（明示）

- サンプル画像の横並び2枚・ギャラリー化
- 価格の併記
- 「公式でサンプルを見る」専用ボタン
- DMM商業の立ち読みビューア埋め込み／専用CTA追加
- まとめ・ランキング記事への適用
- 既存全件の一括同期を必須にしない

---

## 6. 受け入れ条件（実装時）

- [ ] `post_type=regular` の新規で、サンプルURLがあるときだけ1枚出る
- [ ] URLが無い／BJ／DMM商業はセクションなし
- [ ] らぶカルは API の `jp-*` を使う（`js-*` 禁止）
- [ ] DLsite は `modpub` の `_img_smp*` を使う（100x100 resize 禁止）
- [ ] 表示幅がモバイルで破綻しない（max-width）
- [ ] 既存遡及は任意・バッチ分割可能
